# Cryptography and Security Fundamentals: Labs

Hands-on lab write-ups from the MEng Cyber Security programme at the University of Limerick. Each lab has the topology, working configs, Wireshark evidence and a short security analysis.

| Lab | Topic | Tools | Status |
|---|---|---|---|
| [Lab 1](lab1-telnet-vs-ssh/) | Telnet vs SSH, credential exposure in packet captures | GNS3, Cisco IOS, Wireshark | Done |
| [Activity](encryption) | AES-CBC, key sizes, padding, ECB vs CBC | Python, PyCryptodome | Done |
| Lab 2 | IPSec site-to-site VPN with traffic analysis | GNS3, Cisco IOS, Wireshark | In progress |

## Skills shown

- Network device configuration (Cisco IOS)
- Packet capture and protocol analysis (Wireshark)
- Secure remote administration and cryptographic protocol basics
- Technical writing with evidence
